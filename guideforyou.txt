If your classmates didn't use the git clone command but already have a folder with files on their computer (or they just started a new project), they need to manually "link" their local folder to your GitHub repository.

Here is how they find the link and connect their project using git remote.

1. Where to get the link?

If they don't have the link yet, they should go to your GitHub repository page:

Click the green "<> Code" button.

Copy the URL under the HTTPS tab.

For your repo, it is: https://github.com/Crsrll/Platform-based.git

2. How to link a local folder (If they didn't clone)

If they have a folder on their computer and want to connect it to your GitHub repo for the first time, they should run these commands inside that folder:

 
# 1. Initialize the folder as a Git repository
git init

# 2. Connect the folder to your GitHub repo
# (Replace the URL if it's different)
git remote add origin https://github.com/Crsrll/Platform-based.git

# 3. Verify that it worked
git remote -v

[3][4][6][7][8][9]* git remote add origin [URL]: This creates a shortcut named origin that points to your GitHub link.

3. How to check the link (If they forgot it)

If they are already working in a Git-enabled folder but aren't sure which repository it's connected to, they can run:
git remote -v

The output will look like this:

origin  https://github.com/Crsrll/Platform-based.git (fetch)
origin  https://github.com/Crsrll/Platform-based.git (push)
[10]

4. Helpful "First Time" Commands

To push their work for the first time after linking:

 
git add .
git commit -m "My first commit"
git push -u origin main

[11]

Summary for Classmates:

git remote add origin [URL]: Use this if you started a folder locally and need to connect it to GitHub.[2][3][7][8][11]

git remote -v: Use this to check if you are connected to the right repository.[3][4][6][8][12][13]

git remote set-url origin [URL]: Use this if you accidentally connected to the wrong link and need to fix it.
